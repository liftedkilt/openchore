The screen's greeting line: a salutation and the person's first name, set in the skin's display face.

- **Props:** `salutation` ("Morning", "Afternoon", "Evening"; defaults to "Hi") and `name`.
- The name is wrapped in `<em>`, which is italic only where the `--display-italic` dial says so (Sunroom).
- Use it once per screen, at the top of a person's own screen. Never use it on shared House screens, which greet the household ("Good afternoon. Who's here?").
