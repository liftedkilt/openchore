The one primary action on a screen, plus a quiet text button for the way back.

- **Props:** `variant` (`primary` or `quiet`), `block` (full width), `icon` (a trailing icon, such as `chev` for "Next") and `onClick`.
- Primary uses `accent` with `on-accent`. On a Tint screen that is the person's own colour.
- Use one primary per screen.
