The OpenChore line icon set, drawn inline so it takes `currentColor` and the skin's stroke weight.

- **Props:** `name`, `size` (px; defaults to 22) and `fill` (for the solid star and flame).
- Icons sit in a 24 grid with round caps and joins. The stroke weight comes from the `--icon-stroke` dial.
- `OpenChore.ICON_NAMES` lists every name.
